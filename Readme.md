# 🏦 Banking Risk & Fraud Analysis using SQL, Python & Tableau

## 📌 Project Overview

This project demonstrates an end-to-end Banking Risk & Fraud Analysis workflow using SQL, Python, and Tableau. The objective is to analyze banking transactions, identify transaction patterns, monitor customer behavior, and build an interactive dashboard for business intelligence and risk monitoring.

The project covers data cleaning, SQL analysis, Python-based exploratory data analysis (EDA), KPI generation, and an interactive Tableau dashboard.

---

## 🎯 Project Objectives

- Analyze customer transaction behavior.
- Monitor banking transaction trends.
- Identify high-value and high-risk transactions.
- Analyze transaction channels and customer demographics.
- Build an executive dashboard for business insights.
- Demonstrate an end-to-end data analytics workflow.
